How it works:

  1. Add your measurements - choose XY, histogram or multivariate data, then paste or type your values and uncertainties.
  2. Choose a model from the library or write your own equation.
  3. Set starting values (estimate them automatically or adjust the curve until it follows your data), then press Fit.

    Tip: Stuck? Give your data and your model’s equation to an AI model, ask it for starting values, and enter them manually. If you just need the fit rather than practice choosing values, this is the recommended shortcut.

  4. Read your results: parameters with uncertainties, χ²/NDF, p-value and residuals. Export the plot, or take the parameters into Analyze Data to calculate further quantities.

Choose an interface

Choose the arrangement you find more comfortable for entering data and reviewing a fit.

Standard (Recommended)

The Standard interface uses a spacious, minimal appearance with separate pages for data, fit settings, and results. Each page provides more space for the fields or results you are working with, and you can move between them as needed.

Open Standard UI

Compact

The Compact interface uses a retro desktop appearance and displays data, fit settings, and results together. Controls are kept close together so you can adjust a fit and inspect its results without switching pages.

Open Compact UI

Compact and Standard share your current analysis within this browser.

What is ROOT?

ROOT is CERN’s open-source C++ framework for scientific data analysis, with Python bindings. It provides histograms, function fitting, statistical modelling, and storage and processing of large datasets.

This tool uses ROOT for χ² and binned Poisson-likelihood fits, parameter uncertainties, and fit diagnostics. JSROOT displays the resulting graphs in the browser.
